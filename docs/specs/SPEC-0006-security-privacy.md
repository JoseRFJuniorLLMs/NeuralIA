# SPEC-0006 — Security and Privacy

**Status:** Normative

Defaults:
- HTTP(S) only;
- no embedded URL credentials;
- local filesystem paths are rejected and MUST NOT become remote search queries;
- no site JavaScript in Reader;
- bounded Reader body, redirects, deadline and concurrency;
- every Reader redirect is validated before the next request;
- public Reader DNS resolution rejects loopback/private/link-local/reserved IP destinations;
- operating-system TLS certificate verification;
- no NeuralIA cloud account;
- bounded local history only;
- no default remote telemetry.

Remote HTML is untrusted input. Reader output is generated from escaped text blocks, not copied raw markup, and is served with a Content Security Policy that forbids scripts, connections, frames and objects.

Full Web mode inherits the patch level and sandbox model of the installed system WebView runtime. New sensitive WebView permission requests are denied by default. Top-level navigation on remote web surfaces is restricted to HTTP(S) plus `view-source:`; the `neuralia:` navigation scheme is rejected there and survives only for internal Reader links.

Remote WebView surfaces have a bounded WebView2 message channel, not ambient native authority. Each JSON message is limited to 8 KiB, belongs to a closed action schema, and must carry a per-WebView capability token generated by the operating-system CSPRNG and compared in constant time. `chrome.webview.postMessage` and `JSON.stringify` are captured at document-created time; the capability is never placed in a navigation URL, so the Chromium Navigation API cannot observe it as `destination.url`. Unknown actions, unexpected fields, wrong types, invalid columns and local-network split targets are rejected. The floating omnibox remains a native Win32 control: a page may request that it open, but can neither read nor submit what is typed into it.

The optional Gmail monitor is background network activity the user is entitled to know about. When a Google session already exists in the WebView2 profile, a hidden WebView keeps `mail.google.com` loaded so new mail can be announced natively. It consumes the session cookies that are already in the profile to tell whether a session exists; it never asks for a password, never copies those cookies out of the profile, and sends nothing to NeuralIA or to any third party. It only runs while such a session exists, and `NEURALIA_NO_GMAIL=1` disables it.

Local history writes MUST occur off the UI thread and retention MUST be bounded. The user MUST have a local clear-history action.

The repository MUST NOT contain secrets, cookies, tokens, private certificates, or user history.
