# SPEC-0009 — UI/UX

**Status:** Normative

The official identity is the supplied NeuralIA mark: white neural symbol on a black rounded square. The product UI is monochrome, spacious, text-first, and deliberately avoids dashboard clutter.

## Home

The home surface contains the logo, product name/tagline, one omnibox, one primary action, explicit IA/Reader/Web actions, and concise grammar help.

## Reader

Reader prioritizes comfortable line length, typography, headings, quotes, and code. It always exposes Home and Open full page.

## Keyboard

Enter submits the omnibox. Escape returns home from external content in the Windows shell. The native-shell phase SHOULD add Ctrl+L and Alt+Left/Right.

Controls require visible focus and text/accessible labels; essential state must not rely on color alone.
